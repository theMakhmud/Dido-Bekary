# Фирменный стиль Home Cake by Dido

Домашняя кондитерская в Ташкенте: чизкейки, Сан-Себастьян, десерты в посуде, пирожные, клубника в шоколаде. Сайт — каталог с корзиной + торты под заказ. Клиенты приходят из Instagram, почти все с телефона, среди них есть пожилые люди.

## Приоритет правил

1. Этот скилл важнее общих дизайн-советов. Если `frontend-design` предлагает смелое решение, которое противоречит правилам ниже, — следуй этому скиллу.
2. Никаких «эстетических рисков»: никакого брутализма, неона, тёмной темы, кислотных градиентов, сложной анимации. Настроение — **тёплый минимализм**.

## Настроение

- Много светлого пространства, спокойный ритм, ничего лишнего.
- Главные герои — **крупные фотографии десертов**. Интерфейс им не мешает.
- Тёплый, «домашний» характер — как у акварельного логотипа: мягкие скругления, тонкие линии, деликатные акценты. Не холодный корпоративный минимализм.

## Цвета

Палитра взята из логотипа. Все цвета задаются через CSS-переменные / токены Tailwind, не хардкодом.

| Токен | Код | Где использовать |
|---|---|---|
| `brand` | `#5A857E` | Фирменный зелёный: логотип, иконки, крупные заголовки (от 24px), декоративные элементы |
| `brand-strong` | `#47706A` | **Кнопки, ссылки, мелкий цветной текст** — контраст достаточный для чтения |
| `brand-deep` | `#2F4A46` | Заголовки и тёмные акценты |
| `sage` | `#A7BAB6` | Светлые акценты, рамки, разделители, фон бейджей |
| `olive` | `#A7A98D` | Второстепенный акцент |
| `cream` | `#F7F8F4` | Основной фон страниц |
| `white` | `#FFFFFF` | Фон карточек, полей ввода |
| `gold` | `#A79677` | Редкий декоративный акцент (не для текста) |
| `rose` | `#E0BDB5` | Редкий акцент: бейджи «новинка», праздничные элементы |
| `ink` | `#3D3A35` | Основной цвет текста (тёплый тёмно-серый, не чистый чёрный) |

### Контраст — обязательно (WCAG AA)

Проверено:
- `#5A857E` на `#F7F8F4` — 3.9:1 → **только для крупного текста (≥24px) и декора**, не для обычного текста.
- Белый на `#5A857E` — 4.1:1 → **не использовать для кнопок**.
- Белый на `#47706A` — 5.5:1 ✓ → основные кнопки.
- `#47706A` на `#F7F8F4` — 5.2:1 ✓ → ссылки, цветной текст.
- `#3D3A35` на `#F7F8F4` — 10.6:1 ✓ → основной текст.
- `gold` и `sage` — никогда не использовать для текста.

## Шрифты

Шрифты должны поддерживать **кириллицу и узбекскую латиницу** (oʻ, gʻ, ʼ). Подключать через `next/font`.

- Заголовки: элегантный шрифт с засечками с поддержкой кириллицы (кандидат — Cormorant Garamond; финальный выбор согласовать с владельцем).
- Текст и интерфейс: читаемый гротеск с кириллицей (кандидат — Manrope или Inter).
- Каллиграфию из логотипа не повторять шрифтом — логотип вставляется картинкой.

## Удобство для всех (в том числе пожилых)

- Базовый размер текста — **18px** на мобильном, не меньше 16px нигде.
- Кнопки и кликабельные зоны — **минимум 48×48px**.
- Главное действие на экране одно и заметное (например, «В корзину», «Оформить заказ»).
- Текст на кнопках — словами, а не только иконками. Иконки — с подписью.
- Цена крупно и сразу видна.
- Формы: крупные поля, понятные подписи над полем (не только placeholder), понятные сообщения об ошибках.
- Никаких мелких серых подписей, исчезающих меню при наведении, автокаруселей.

## Компоненты и формы

- База — shadcn/ui, перекрашенный в токены выше. Не плодить свои компоненты, если есть подходящий в shadcn.
- Скругления мягкие: карточки и кнопки ~12–16px.
- Тени — очень лёгкие или вообще без теней; разделение блоков — фоном и отступами.
- Карточка товара: большое фото (соотношение 4:5 или 1:1, одинаковое во всём каталоге), название, цена, кнопка. Минимум текста.

## Фото

- Всегда `next/image`, с `alt` на нужном языке (поле `alt` из Media).
- Единое соотношение сторон в сетках.
- Фото не перекрывать текстом без подложки.

## Mobile-first

- Сначала вёрстка для экрана ~375px, потом расширение.
- Проверять каждую страницу скриншотами через Playwright MCP: 375px (телефон) и 1280px (десктоп).

## Языки

- Любой текст интерфейса — на русском и узбекском (латиница). Вёрстка должна выдерживать более длинные узбекские слова без поломки.
